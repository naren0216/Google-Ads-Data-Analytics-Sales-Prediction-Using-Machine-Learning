This project analyzes Google Ads campaign performance and predicts revenue using Python. It includes data cleaning, feature engineering, metric calculation (CTR, CPC, Conversion Rate, ROAS), and visualization using Matplotlib and Seaborn.

A Linear Regression model predicts Sale Amount from campaign metrics, and model efficiency is evaluated using R², MAE, and RMSE. Prediction plots include actual vs predicted revenue, residuals, error distribution, and sorted line comparisons, providing actionable insights for campaign optimization.

Tech Stack: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
Key Skills: Data Analysis, Data Visualization, Machine Learning, Model Evaluation, Digital Marketing Analytics
